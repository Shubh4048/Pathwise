# Pathwise AI

Your AI-powered roadmap to a career in tech.

Pathwise AI is an AI-powered career development platform designed to help students and aspiring technology professionals understand **where they are, where they want to go, and what they should do next**.

Instead of giving users a generic list of courses or technologies, Pathwise generates a personalized roadmap based on their current skills, goals, and experience.

✨ Features

- 🤖 **AI Career Coach** — Get personalized guidance for your career goals.
- 🗺️ **Personalized Roadmaps** — Generate structured career paths based on your current level and target role.
- 📅 **Daily Tasks** — Break long-term career goals into actionable daily steps.
- 🔥 **Progress & Streaks** — Stay consistent and track your progress.
- 🚀 **Project Guidance** — Turn learning into practical projects and experience.
- 💬 **AI Chat** — Ask questions and get career-focused guidance.
- 🌗 **Dark / Light Mode** — Choose your preferred interface.
- 🔐 **Authentication** — Secure user authentication and session management.
- 💳 **Premium Infrastructure** — Stripe integration for future premium features.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- pnpm
- MySQL

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/pathwise-ai.git
cd pathwise-ai
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Configure environment variables

Create a `.env` file based on `.env.example`.

```bash
cp .env.example .env
```

Add the required API keys and database configuration.

### 4. Set up the database

```bash
pnpm db:push
```

### 5. Start the development server

```bash
pnpm dev
```

The application should then be available locally.

## 🧪 Testing

Run the test suite with:

```bash
pnpm test
```

Type-check the project with:

```bash
pnpm check
```

Format the code with:

```bash
pnpm format
```

## 🏗️ Production Build

```bash
pnpm build
```

Then:

```bash
pnpm start
```

## 🔐 Environment Variables

Never commit your `.env` file or production secrets.

Use `.env.example` as a reference for the required configuration.
